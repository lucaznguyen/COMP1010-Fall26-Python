# Lab 01 Completion Checklist

Use this checklist before submitting. It summarizes the requirements in the Lab 01 handout; any score breakdown and late-submission penalties are determined by the official course policy.

- The program is written in Python 3.
- Each problem is saved in its own `.py` file using the required filename pattern.
- The program follows the problem's input and output requirements exactly.
- Variables and functions have meaningful names, and comments are used where they help explain the code.
- The solution is your own work and is not copied from or shared with another student.
- The same solution file is submitted to both Codeforces and Canvas before the end of the lab session.
