# Study Tips and Resources

- Read each problem's input, output, and example sections carefully before coding.
- Run your program with the examples and a few additional inputs of your own.
- Keep one source file per problem and use descriptive variable names.
- Ask an instructor or teaching assistant if an instruction is unclear.
