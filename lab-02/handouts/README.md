## Compile a Section Handout in Overleaf

1. Upload the files in [`overleaf-source`](overleaf-source) to an Overleaf project.
2. Set the question file for your section as the main document.
3. Compile with pdfLaTeX. The shared `preamble.tex` and both logo files must remain beside the question source.

The local workspace contained the Overleaf question sources but no exported Lab 02 PDFs or local LaTeX compiler, so this repository keeps the complete question-only source package for compiling in Overleaf. The old 2025 Codeforces URL in the source copies has been updated to the Fall 2026 course group. No solution files are included.
