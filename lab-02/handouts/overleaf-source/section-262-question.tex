\section*{Problem 1: Share the Stickers}

You have \texttt{stickers} stickers to share equally among \texttt{students}. Find how many stickers each student receives and how many stickers are left over.

\subsection*{Input}
\begin{itemize}
    \item One line containing \texttt{stickers} and \texttt{students}, separated by a space, where $0 \leq \texttt{stickers} \leq 10^9$ and $1 \leq \texttt{students} \leq 10^6$.
\end{itemize}

\subsection*{Output}
\begin{itemize}
    \item Print two integers: stickers per student, then stickers left over.
\end{itemize}
\vspace{0.2cm}

\begin{example*}{}{}
\begin{multicols}{2}
\textbf{Example 1}
\begin{verbatim}
Input:
29 4

Output:
7 1
\end{verbatim}
\textbf{Example 2}
\begin{verbatim}
Input:
48 6

Output:
8 0
\end{verbatim}
\end{multicols}
\end{example*}

\section*{Problem 2: Study Room Access}

A study room can be used by someone who has a valid access card and is either a student or a staff member. Given these three yes/no answers, report whether the card is valid, whether the person is a student or staff member, and whether the person can enter. Each answer is the exact word \texttt{True} or \texttt{False}.

\subsection*{Input}
\begin{itemize}
    \item Three lines: whether the person has a valid card, whether they are a student, and whether they are a staff member.
\end{itemize}

\subsection*{Output}
\begin{itemize}
    \item Print \texttt{Card is valid: ...}, \texttt{Student/staff requirement: ...}, and \texttt{Can enter: ...}, each on its own line. Replace \texttt{...} with \texttt{True} or \texttt{False}.
\end{itemize}
\vspace{0.2cm}

\begin{example*}{}{}
\begin{multicols}{2}
\textbf{Example 1}
\begin{verbatim}
Input:
True
True
False

Output:
Card is valid: True
Student/staff requirement: True
Can enter: True
\end{verbatim}
\textbf{Example 2}
\begin{verbatim}
Input:
False
False
True

Output:
Card is valid: False
Student/staff requirement: True
Can enter: False
\end{verbatim}
\end{multicols}
\end{example*}

\section*{Problem 4: Make a Message Tag}

Given a one-word message and a repeat count, repeat the message that many times. Then make a tag from the repeat count, a hyphen, and the repeated message. The hyphen is the literal dash character \texttt{-} between the count and the message.

\subsection*{Input}
\begin{itemize}
    \item Two lines: a word with no spaces (1 to 20 English letters), then a repeat count from 1 to 5.
\end{itemize}

\subsection*{Output}
\begin{itemize}
    \item Print \texttt{Message: } followed by the repeated message. On the next line, print \texttt{Tag: } followed by the repeat count, the literal hyphen \texttt{-}, and the repeated message.
\end{itemize}
\vspace{0.2cm}

\begin{example*}{}{}
\begin{multicols}{2}
\textbf{Example 1}
\begin{verbatim}
Input:
Hi
3

Output:
Message: HiHiHi
Tag: 3-HiHiHi
\end{verbatim}
\textbf{Example 2}
\begin{verbatim}
Input:
Go
1

Output:
Message: Go
Tag: 1-Go
\end{verbatim}
\end{multicols}
\end{example*}
