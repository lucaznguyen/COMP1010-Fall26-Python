# Lab Practice and Submission

Lab practices for Fall 2026 use the [COMP1010 Codeforces group](https://comp1010fall2026.contest.codeforces.com/). Use the contest and section assigned by your instructor.

1. Create or sign in to your Codeforces account and open the COMP1010 group above.
2. Open the contest for the current lab and your assigned section.
3. Write a separate Python 3 program for each problem.
4. Follow the handout's filename pattern `LabX_PY_Z.py`, where `X` is the lab number, `Y` is the problem number, and `Z` is your student ID. For example, a Lab 02 file may be named `Lab2_P1_<YourStudentID>.py`.
5. Submit each solution on Codeforces.
6. Upload the same `.py` files to the matching Canvas assignment before the end of the lab session.

The code submitted on Codeforces and Canvas must match. A submission missing from either platform will not be graded. Follow the official course policy for late submissions and academic honesty.
