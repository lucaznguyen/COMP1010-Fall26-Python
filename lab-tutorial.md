# Lab Practice and Submission

Lab practices for Fall 2026 use the [COMP1010 Codeforces group](https://comp1010fall2026.contest.codeforces.com/).

1. Create or sign in to your Codeforces account and open the COMP1010 group above.
2. Open the Lab 01 contest and solve each problem as a separate Python 3 program.
3. Save each program as a `.py` file using the required filename pattern, for example `Lab1_P1_<YourStudentID>.py`.
4. Submit your solution on Codeforces.
5. Upload the same `.py` file to the Lab 01 assignment in Canvas before the end of the lab session.

The code submitted on Codeforces and Canvas must match. A submission missing from either platform will not be graded. Follow the official course policy for late submissions and academic honesty.
