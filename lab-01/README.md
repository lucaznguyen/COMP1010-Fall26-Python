# Lab 01: Getting Started With Python

**Course:** COMP1010 - Introduction to Programming  
**Week:** 01  
**Date:** September 22, 2026

Lab 01 introduces the Python environment and basic input and output. The official handout contains the submission rules and full problem statements.

## Learning Goals

- Run a Python 3 program in PyCharm.
- Display text with `print()`.
- Read a value from input and use it in a simple calculation.
- Submit each solution on Codeforces and Canvas.

## Problems

1. Print `Hello World!`.
2. Print `Welcome to VinUniversity.`.
3. Read a year of birth, calculate the age using 2026 as the current year, and print the result in the required format.
